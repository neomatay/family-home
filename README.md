# 家 · 家庭伙伴

两个人的家（和三只猫）的家庭协作小应用：把餐厅、冰箱、购物清单这些日常琐事放进一栋可点击的小房子里。

## 这是什么

- **首页是一栋矢量小房子**：厨房亮着灯、冰箱挂着缺料角标、玄关贴着购物清单 —— 点房间进入对应功能，状态用小圆点呈现
- **家庭餐厅**（v0.1 已点亮）：上架学会的菜、标记谁会做、预定今晚吃什么；预定后自动查冰箱，缺的原料直接进购物清单
- **冰箱与库存**：食材 / 日用品 / 猫用三区，低库存提醒
- **营养估算**：按材料份量估算每份热量与碳蛋脂，可手动微调（本地食物库，正式版接入 AI）
- 卧室（健康）、猫角（猫猫管家）、书房（账本）在二期池，房间里写着「还没有整理好」

## 使用

- 在线版（GitHub Pages）：见 About 栏链接
- 本地运行：`python3 -m http.server` 后浏览器打开
- v0.1 数据保存在本机浏览器（localStorage），换设备不同步 —— 云端协作（Supabase）在路上

## 技术形态

单文件 `index.html`，无构建、无依赖，明暗双主题，375px 移动端优先。数据结构与 Supabase 目标表同构（见 [docs/PRD-v0.1.md](docs/PRD-v0.1.md)），未来可迁移微信小程序。
