# 家 · 家庭伙伴

两个人的家（和三只猫）的家庭协作小应用：把餐厅、冰箱、购物清单、周末计划这些日常琐事放进一栋可点击的小房子里。

## 这是什么

- **首页是一栋矢量小房子**：厨房亮着灯、冰箱挂着缺料角标、玄关贴着购物清单 —— 点房间进入对应功能，状态用小圆点呈现
- **家庭餐厅**（v0.1 已点亮）：上架学会的菜、标记谁会做、预定今晚吃什么；预定后自动查冰箱，缺的原料直接进购物清单
- **冰箱与库存**：食材 / 日用品 / 猫用三区，低库存提醒
- **生理期记录**（v0.3 已点亮 · 卧室）：两人各自记录日期、批量补录历史，自动算平均周期、间隔波动、稳定度和预计下次日期
- **周末新鲜事**（v0.5 已点亮 · 书房）：记下想一起干的事、定到哪个周末、做完打个回味值 —— 攒的是数据，之后回顾你们爱干什么、该多干什么
- **猫猫管家**（已点亮 · 猫角）：同源 iframe 嵌入既有的 [cat-health](https://github.com/neomatay/cat-health) 应用 —— 体重体温趋势、用药计划与喂药记录，数据在它自己的 Supabase，主题与「家」联动；猫角钥匙存云端，全家任一设备输一次、其他设备进家自动登录（v0.4）
- **营养估算**：按材料份量估算每份热量与碳蛋脂，可手动微调（本地食物库，正式版接入 AI）
- 账本在二期池（原书房的位置让给了新鲜事）

## 使用

- 在线版（GitHub Pages）：见 About 栏链接
- 本地运行：`python3 -m http.server` 后浏览器打开
- **v0.2 云端协作**：首次打开创建「家」会生成家庭邀请码，另一台手机输入同一邀请码即加入同一份云端数据（Supabase，行级安全按邀请码隔离）
- 建表 SQL 在 [supabase/migration.sql](supabase/migration.sql)（在 Supabase Dashboard → SQL Editor 运行一次即可）

## 技术形态

单文件 `index.html`，无构建、无依赖，明暗双主题，375px 移动端优先。数据存 Supabase（fetch 直连 REST，publishable key + 行级安全），见 [docs/PRD-v0.1.md](docs/PRD-v0.1.md)，未来可迁移微信小程序。
